# Cricket Voice Lab

A local browser interface for testing expressive cricket commentary with Chatterbox Multilingual TTS. Speech is generated by the local Python service; Microsoft browser voices are not used.

## Current local setup

Double-click `start_voice_tester.bat`. The launcher starts the Python service and opens `http://127.0.0.1:8771`.

The current setup expects its Python environment under `work/chatterbox-env` in the surrounding workspace and the following Chatterbox model files in the Windows Downloads folder:

- `t3_mtl23ls_v3.safetensors`
- `s3gen.pt`
- `ve.pt`
- `conds.pt`
- `grapheme_mtl_merged_expanded_v1.json`

Model weights, Python environments, caches, and generated audio are intentionally excluded from this repository.

## Voice controls

- English and Hindi generation
- Commentary mood presets
- Exaggeration and CFG weight
- Temperature and repetition penalty
- Repeatable seed
- Pace, energy, and tone interface controls

The application generates `commentary.wav` locally. CPU generation works but is significantly slower than generation on a CUDA-capable GPU.
